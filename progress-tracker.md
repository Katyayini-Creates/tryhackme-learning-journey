## 3. Operating Systems Basics

| Room | Key Learning |
|---|---|
| Operating Systems: Introduction | Learned the purpose of an operating system and how it manages hardware resources and provides services to applications. Explored the distinction between kernel space and user space, the role of system calls in allowing applications to request OS services, and how the operating system acts as an interface between applications and hardware. |
| Windows Basics | Explored the evolution from command-line-based interaction to graphical user interfaces in modern Windows systems. Learned how users authenticate and access their desktop workspace, including the taskbar, Start menu, and system settings. Also explored Windows Security, Microsoft Defender Firewall, and essential Windows settings used to manage and protect a system. |
| Linux CLI Basics | Learned the fundamentals of Linux, a Unix-like operating system widely used in cybersecurity, with distributions such as Kali Linux, Ubuntu, and Debian. Practiced essential Linux commands, including `pwd` to display the current working directory, `ls` and `ls -l` to list files and directories, `cd` to navigate the filesystem, `find` to locate files, `cat` to display file contents, `whoami` to identify the current user, `uname` and `uname -a` to retrieve system and kernel information, and `df -h` to inspect disk space usage in a human-readable format. | Windows CLI Basics | Learned how to interact with Windows through Command Prompt (CMD), a command-line interface for executing commands and managing the system. Used `dir /s filename` to search for a specified file throughout the current directory and its subdirectories, and learned to navigate to the file's containing directory using its full path. Used the `type` command to display a text file's contents directly in the terminal. Explored `whoami` to identify the current user, `hostname` to display the computer's name, and `systeminfo` to retrieve system details such as the operating system version, processor, memory, and system type. Also practiced `ipconfig` to inspect network configuration, including IP addresses and the default gateway. Developed a foundation in Windows filesystem navigation, file inspection, system information gathering, and basic network reconnaissance through the command line. |
| Operating System Security | Learned about OS security threats, including weak passwords, brute-force and dictionary attacks, weak file permissions, and malware. Explored authentication factors, the principle of least privilege, and the CIA triad. Practiced SSH for remote access, learned about host keys and privileged accounts, and used `history` and `su - root` to understand Linux shell history and root access. |
