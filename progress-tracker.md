## 2. Computer Fundamentals

| Room | Key Learning |
|---|---|
| Inside a Computer System | Studied the physical components that make up a computer system, including the motherboard, CPU, RAM, GPU, input and output devices, and the sockets and slots used to connect hardware components. Learned how components such as RAM modules and GPUs connect to the motherboard and how different hardware components work together to process data and execute instructions. |
| Computer Types | Explored different types of computing devices, including desktops, laptops, smartphones, and tablets. Understood that computers differ in size, processing power, portability, and intended purpose, while sharing fundamental computing principles. |
| Client-Server Basics | Learned how two systems communicate using the client-server model. Understood that a client requests a service or resource while a server processes the request and provides a response. Explored how a system's role depends on the service and communication context, along with the basics of network protocols and HTTP/HTTPS communication between clients and web servers. |
| Virtualisation Basics | Learned why virtualization emerged as an efficient way to use physical computing resources. Understood how a single physical server can host multiple virtual machines, each with its own operating system and isolated environment. Connected this concept to tools such as VirtualBox and explored how virtualization improves resource utilization, flexibility, and workload isolation compared with dedicating a separate physical server to every task. |
| Cloud Computing Fundamentals | Studied how cloud computing provides computing resources and services over a network and how virtualization helps enable flexible resource allocation. Explored the relationship between virtualization, containerization, and cloud infrastructure, along with the role of cloud platforms such as Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). Understood why cloud computing is widely used for scalable infrastructure, storage, networking, and application deployment. |
